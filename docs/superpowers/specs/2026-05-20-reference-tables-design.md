# 参照テーブル表示機能 設計書

## 概要

問題出題時に参照用の表をアコーディオン形式で表示する。

- 2級・3級の確認問題 → 勘定科目表（アコーディオン）
- 実践！電卓問題 → 財務諸表ガイド（アコーディオン）

---

## コンポーネント設計

### 1. `AccountTitlesTable.tsx`

**役割**: 2級・3級の勘定科目を5カテゴリに色分けした参照テーブル

**Props**: なし（固定データ）

**表示場所**: `LessonClient.tsx` の `QuizSection` 内、問題文の直上

**表示形式**: アコーディオン（デフォルト: 閉じた状態）

**カテゴリ構成**:
| カテゴリ | 色 | 主な科目（例） |
|---|---|---|
| 資産 | 青系 | 現金、当座預金、受取手形、売掛金、繰越商品、建物、備品、土地、のれん、投資有価証券 |
| 負債 | 赤系 | 支払手形、買掛金、借入金、前受金、未払費用、社債、退職給付引当金 |
| 純資産 | 緑系 | 資本金、資本準備金、利益準備金、繰越利益剰余金 |
| 収益 | 黄系 | 売上、受取手数料、受取利息、受取配当金、固定資産売却益 |
| 費用 | 灰系 | 仕入、給料、旅費交通費、支払利息、減価償却費、貸倒引当金繰入 |

2級固有の科目も含める（売買目的有価証券、繰延税金資産、退職給付費用 など）。

---

### 2. `FinancialStatementsGuide.tsx`

**役割**: 問題の勘定科目を財務諸表形式で示す参照ガイド

**Props**: `accounts: string[]`（`expectedAnswers` のキー一覧）

**表示場所**: `CalculatorClient.tsx` の左ペイン、取引一覧の上

**表示形式**: アコーディオン（デフォルト: 閉じた状態）

**内容**:
1. **構造テンプレート**: B/S（借方=資産 / 貸方=負債+純資産）と P/L（借方=費用 / 貸方=収益）のフォーマット図解
2. **科目分類**: `accounts` を資産・負債・純資産・収益・費用に自動振り分けし、該当箇所に表示

## 制約

- アコーディオンはデフォルトで閉じた状態
- 外部ライブラリは使用しない（`useState` で開閉制御）
- 既存のデザイン（dark テーマ、Tailwind CSS）に合わせる
